# assets/

Screenshots, photos, QR codes and video for this deck. Keep everything the
deck shows in here, so it works offline and travels as one folder.

- Name files by what they show: `tracker-phone.png`, `qr-links.png`.
- Crop out names, emails and anything private before it goes in.
- Big photos: resize to about 2000px wide; the stage is 1920x1080.
